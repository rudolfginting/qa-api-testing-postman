# API Testing Overview

## Objective
Validate API functionality, response accuracy, and request handling using Postman.

## API Endpoints Tested
- GET /users
- GET /users/1
- POST /users

## Testing Activities
- Validate status code responses
- Verify JSON response structure
- Validate API request and response behavior
- Perform positive testing scenarios

## Example Validation
### GET /users
Expected:
- Status code 200
- Response contains user data

### POST /users
Expected:
- Status code 201
- New user object returned

## Tools Used
- Postman
- REST API
- JSONPlaceholder API
