# QA API Testing Portfolio (Postman)

This repository showcases basic API testing practices using Postman for QA purposes.

## Project Overview
Performed API testing on public REST APIs to validate request handling, response structure, status codes, and data consistency.

## Testing Scope
- GET Request Testing
- POST Request Testing
- Response Validation
- Status Code Validation
- JSON Response Validation

## Tools Used
- Postman
- REST API
- JSON

## API Testing Activities
- Validated successful API responses
- Tested invalid requests and error handling
- Verified JSON response structure
- Performed basic endpoint validation

## Repository Structure
- `/collections` → Postman collection
- `/test-documentation` → API testing explanation
